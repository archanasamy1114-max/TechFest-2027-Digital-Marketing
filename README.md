# TechFest 2027 – Digital Marketing Campaign & Performance Analytics

## Project Overview
This portfolio project demonstrates a digital marketing campaign plan for a hypothetical technology event called TechFest 2027.

## Project Activities
- Marketing strategy planning
- Social media content calendar
- SEO keyword analysis
- Google Ads campaign planning
- Campaign performance analysis using Excel
- Dashboard creation using Microsoft Power BI

## Tools Used
- Microsoft Excel
- Microsoft Power BI

## Dashboard Metrics
- Impressions
- Clicks
- Advertising Spend
- Registrations
- Platform-wise Click Performance
- Campaign-wise Registrations

## Data Note
All campaign records and performance figures in this project are illustrative sample data created for learning and portfolio demonstration. They do not represent a real advertising campaign.

## Project Status
Marketing planning, sample performance analysis, and Power BI dashboard completed.
